# VisionAI Studio starter

This is a beginner-friendly, mobile-responsive static website starter.

## Files
- `index.html` — includes the layout, styling, and JavaScript.

## What works now
- Mobile-friendly interface
- Creation mode selection
- Prompt character counter
- Local image upload preview
- Prompt preparation and copy
- Draft pricing section

## Important
AI image/video generation, user accounts, saved history, and payments are NOT connected yet. This starter does not pretend to generate AI media. To enable real generation, we must choose a provider with an available free allowance or deploy compatible open-source models; those services can have limits.

## Run it
Open `index.html` in a browser, or upload it to a static hosting service.
